To build the project, I experimented with many convolutional neural network architectures to find a balance between accuracy, speed and overfitting. I firstly did a model with only one convolutional layer, a pooling layer and a fully connected output. It did run quickly, however the accuracy wasn’t very high on the testing data. I then added a 2nd layer with more filters (from 32 to 64) and added another pooling layer. This allowed the network to extract ore abstract features from the images, and the accuracy rose significantly. However, after several epochs, it began to overfit as even though the training accuracy kept improving the testing accuracy plated. I then added a dropout layer between the dense layers, which improved generalization and pushed the accuracy to around 95%.

I tested different image sizes (20x20, 30x30, 40x40) and saw that 30x3- gave the best trade off between resolution and efficiency. Normalizing the image pixel values to range between 0-1 by dividing by 255 helped stabilize training and using the Adam optimizer worked better than stochastic gradient descent. Overall, the performance increased not only by increasing the number of layers, but also using dropout layers and data preprocessing. The final model has 2 Conv2D layers (32 and 64 filters), 2 pooling layers (MaxPooling), uses ReLu activation, and 50% dropout
